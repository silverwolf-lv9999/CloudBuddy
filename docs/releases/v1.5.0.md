## 这一版更新了什么

本机会话的框架照 [RikkaHub](https://github.com/rikkahub/rikkahub) 重做了一遍，并补齐了
只作用于本机会话的技能、MCP 与提示词。完整版 / 共存版用户可用的内容：

### 一、会话消息流持久化（修复「消息消失」）

- **会话的真相是整条消息流**：思考、工具调用、过程叙述、回答、失败与中断记录一条不少地
  落盘（一个会话一个 JSON 文件，原子写入），重进会话时按原顺序放回去。此前只存
  「提问 + 回答」两句话，中途退出再进，思考与工具过程全部丢失。
- **先落盘再执行**：发送前消息就写进历史，失败与中断照样留痕（界面上可见，但不会回放给
  模型）；进程被系统回收留下的「运行中」工具，重进时收尾成失败并标注「已中断」。
- **思考内容显示**：兼容端点返回的 reasoning 流现在会作为思考气泡出现在对话里
  （此前 Koog 框架把它丢掉了）。
- **端点解析修正**：`https://api.example.com/v1` 这种带路径前缀的地址不再 404。

### 二、本机技能 / 本机 MCP / 提示词片段

- **提示词片段**：编码规范、项目约定这类内容拆成一条条片段，各有开关、注入位置与顺序；
  一条都不启用时系统提示词逐字不变。
- **本机技能**：目录式 `SKILL.md`（带 frontmatter），支持导入与启停；系统提示只放技能
  名字与描述，模型通过 `use_skill` 工具按需读全文（渐进披露）。技能目录里的补充文件
  可被模型读取，逃出目录的路径一律拒绝。
- **本机 MCP**：url 型（SSE / streamable HTTP）服务器可桥进本机会话，远端工具与沙箱
  工具、技能工具合并成一张表；连接按配置缓存，失败降级不炸会话。MCP 卡片上
  「云端会话 / 本机会话」两个开关独立控制。
- 以上三项只作用于**本机会话**；云端会话的技能 / MCP 仍由云端下发执行，两套互不影响。

### 三、设置页重排

设置首页按**能力归属**分成六栏：账号与额度、会话引擎、云端会话（技能 / 连接器 / MCP）、
本机模型（接口与模型 / 提示词片段 / 本机技能）、通用、其他。想找「给自定义 API 用的
设置」不会再摸到云端那一堆里。

### 四、应用内更新适配三包

「检查更新」现在**按当前档位挑对应的安装包**：基础版拿 `-base-`、共存版拿 `-plus-`、
完整版拿不带中缀的那个——不会点了更新却装成另一个档位。三个包同一把正式签名，
共存版也能直接覆盖升级（此前它被禁止检查更新）。「关于」页会标明当前装的是哪一档。

### 五、其他

- 会话列表卡片不再显示模型名（长串 ID 占一整行还认不出来）。
- 清理会话时修复了一个竞态：刚删的会话可能被排队中的写盘任务「复活」。
- 本机技能库读取补充文件时补上目录存在性检查。

## 三个包有什么不同

同一份代码，三个包，桌面上都叫「云伴 WorkBuddy」，靠**包名**区分：

| | 基础版 | 完整版 | 共存版 |
|---|---|---|---|
| 文件 | `CloudBuddy-1.5.0-base-release.apk` | `CloudBuddy-1.5.0-release.apk` | `CloudBuddy-1.5.0-plus-release.apk` |
| 包名 | `cn.cloudbuddy.app` | `cn.cloudbuddy.app` | `cn.cloudbuddy.app.plus` |
| 云端对话 | 有 | 有 | 有 |
| 本机 agent | **无** | 有 | 有 |
| 第三方 API / 技能 / MCP | **无** | 有 | 有 |
| 终端命令行 | **无** | 有 | 有 |
| 与谁共存 | 与完整版**互斥** | 与基础版**互斥** | 可与前两者**同时装** |

**基础版与完整版是同一个应用的两个档位。** 包名相同，装完整版就是覆盖升级，
登录态、会话、设置原样保留；哪天想退回基础版，再装一次基础版即可，同样不丢数据。
两个包都沿用上游的包名与正式签名，所以也能覆盖上游发的老版本。

**共存版**换的是包名，所以能和上面两个同时装——给"基础版留着不动、另外再装一个完整版"的人。
代价是全新的一份数据，需要重新登录一次。

**基础版不含的东西是真不含**：Koog 与终端界面在构建时就不进基础版，
不是藏起入口。

### 怎么选

- 只用云端模型、图省事、想要最小的包 → **基础版**
- 要用自定义端点 / 终端 / 本机技能与 MCP → **完整版**
- 上面两个都想要，还得同时留着 → **完整版 + 共存版**
