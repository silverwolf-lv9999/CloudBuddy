## 这一版更新了什么

修复自定义 API（本机）会话的历史消息消失问题。

### 现象

本机会话退出再进（有时是使用中），整段历史被清空。1.5.0 已修过一轮落盘竞态，
但那只是入口之一——真正的漏洞在云端同步通道没关干净。

### 根因

本机会话在云端是空壳（推理在本机、云端从不收到消息），但客户端仍有多条路径会
为它建立云端 ACP 连接：历史迁移、模型推送、静默补历史。每条连接的云端事件推送
都会用**空的云端快照整份覆盖**界面与消息流——云端没有内容，覆盖一次历史就消失
一次。另外引擎归属记录按账号保存，换账号后判定回落成「云端」，会话被错误地走
云端回放通道。

### 修法（三层）

1. **出口拦截**：界面消息、模型列表、静默补历史三处见到本机会话直接忽略云端数据。
2. **入口拦截**：本机会话不再允许建立云端 ACP 连接；历史迁移改用一次性临时连接。
3. **判定自愈**：本机归属改按「归属记录 ‖ 自定义标记 ‖ 本机消息流有内容」三条件
   判定，记录丢失（换账号等）时自动改回，恢复、发送、对账全走同一口径。

### 升级注意

从 1.5.0 直接覆盖安装即可；历史数据在升级前就已落盘的会话不会被本次修复找回
（1.5.0 及更早版本中被空快照覆盖掉的内容云端没有副本）——修复防止的是再次发生。

## 三个包有什么不同

与 1.5.0 相同：基础版与完整版同包名可互相覆盖，共存版可与前两者并存。
完整版 / 共存版才包含本机 agent、第三方 API、技能与 MCP、终端命令行。
详见 1.5.0 的 Release 说明。
