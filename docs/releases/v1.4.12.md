## 这一版更新了什么

接在上游 `1.4.11` 之后，这是第一个把「云端对话 + 本机 agent + 终端」装进同一份代码的发布版。
此前 `1.5.x`–`1.7.0` 的改动都在本地测试线上，从未对外发布，全部并入本版。

### 一、本机 agent 与第三方 API（完整版 / 共存版）

- **两套推理引擎**：云端模型（扣积分、跑在云端 agent 里、对话可跨端回放）与本机 agent
  （填任意 OpenAI 兼容端点，由本机 Koog 推理）。会话类型在新建时定下，之后不互转，
  列表里有「云端 / 本机」标签，两套的历史与凭据各自独立。
- **工具仍在云沙箱里执行**：本机推理只替换"谁在思考"，读写文件、跑命令还是走同一个
  会话的 E2B 沙箱，不扣积分也不产生云端对话记录。
- **模型条目化**：每个模型可单独设显示名、是否思考、思考强度、上下文轮数；
  从端点拉到的模型清单只进"候选池"，勾选的才进"我的模型"。兼容旧版纯 ID 存储。
- **思考字段注入**：`reasoning_effort` 的三种写法在 HTTP 层并进请求体，
  解决部分兼容端点"设了不生效"的问题。

### 二、终端命令行（完整版 / 共存版）

按手机终端的习惯重做，不是网页控制台的移植：

- **多标签**，每会话最多 5 个；标签间互不打断，agent 的命令固定进第一个标签，
  命令日志按「会话#标签」分区，后台标签的输出不会串到前台。
- **按停保留已收到的输出**：中断单独标记为「已中断」，不算失败。
  此前一点结束就整屏清空，`ping` 这类长命令的输出全丢。
- **ANSI 16 色**、回车覆盖行、长输出 400 行分页展开、可选中复制。
- 输入框在光标处插符号、上下键翻双向历史、带草稿；字号四档可调；
  新输出只在贴底时自动跟随，往上翻看历史不会被拽回底部。

### 三、设置与账号

- **设置拆成二级页**：推理与模型、外观与对话、技能与扩展、关于与更新各成一页，
  返回键回首页。此前一千多行堆在一页，换个主题要滚过全部模型参数。
- **账号与额度**成为首页第一栏：头像首字 + 昵称 + 脱敏手机号、积分余额与等级、
  连续签到天数与签到按钮；首页放不下的（多账号切换、完整套餐与有效期、云端环境）
  在二级页，摘要与明细不重复。
- **滑动性能**：卡片阴影归零、分组标题独立 `contentType`、模型列表默认只组合前 8 个。

### 四、其他

- **附件**：选中的文件先写进沙箱 `/workspace/uploads/…`，再把路径交给 agent。
- **提问与权限确认**：云端停下来问话时弹选择卡片，支持多问题、多选、选项说明与自行输入。
- **工作区**：浏览、新建目录、上传、删除、下载到系统 Download 文件夹。
- **上游修复**：工具调用中重进会话不再直接跳「已完成」，并会补回后续消息。

## 三个包有什么不同

同一份代码，三个包，桌面上都叫「云伴 WorkBuddy」，靠**包名**区分：

| | 基础版 | 完整版 | 共存版 |
|---|---|---|---|
| 文件 | `CloudBuddy-1.4.12-base-release.apk` | `CloudBuddy-1.4.12-release.apk` | `CloudBuddy-1.4.12-plus-release.apk` |
| 包名 | `cn.cloudbuddy.app` | `cn.cloudbuddy.app` | `cn.cloudbuddy.app.plus` |
| 云端对话 | 有 | 有 | 有 |
| 本机 agent | **无** | 有 | 有 |
| 第三方 API | **无** | 有 | 有 |
| 终端命令行 | **无** | 有 | 有 |
| 体积 | 12 MB | 15 MB | 15 MB |
| 与谁共存 | 与完整版**互斥** | 与基础版**互斥** | 可与前两者**同时装** |

**基础版与完整版是同一个应用的两个档位。** 包名相同，装完整版就是覆盖升级，
登录态、会话、设置原样保留；哪天想退回基础版，再装一次基础版即可，同样不丢数据。
两个包都沿用上游的包名与正式签名，所以也能覆盖上游发的老版本。

**共存版**换的是包名，所以能和上面两个同时装——给"基础版留着不动、另外再装一个完整版"的人。
代价是全新的一份数据，需要重新登录一次。

**基础版不含的东西是真不含**：Koog 与终端界面在构建时就不进基础版，
不是藏起入口。体积差的那 3 MB 就是它们。

### 怎么选

- 只用云端模型、图省事、想要最小的包 → **基础版**
- 要用自定义端点 / 终端 / 本机 agent → **完整版**
- 上面两个都想要，还得同时留着 → **完整版 + 共存版**
